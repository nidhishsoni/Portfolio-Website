# Personal Portfolio Website

## Overview
This is a full-stack Personal Portfolio Website project created to showcase projects, skills, and contact information.

The project uses frontend, backend, and database technologies to build a complete web application.

---

## Technologies Used

### Frontend
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

---

## Features
- Responsive portfolio homepage
- About section
- Skills section
- Projects section
- Contact information
- Backend server using Node.js
- MySQL database integration

## How to Run the Project

### Frontend
Open the following file in any web browser:

frontend/index.html

### Backend
Open terminal inside the backend folder and run:

npm init -y

npm install express mysql2 cors

node server.js

### Database
Run the SQL commands from:

database/portfolio.sql

using MySQL Workbench.
